01

Playfair cipher

Builds a 5×5 key square from a secret keyword, then encrypts your text two letters at a time using geometric rules — same row shifts right, same column shifts down, different row+column swaps corners. This breaks the simple letter-to-letter mapping that defeats basic substitution ciphers.

02

Columnar transposition

Takes the Playfair output and writes it into a grid. The columns are then read out in an order determined by the alphabetical rank of each key character. This shuffles the positions of all characters, so even if an attacker partially breaks one layer they still face a scrambled arrangement.

positional scramble key-ranked columns grid transposition
03

DES block cipher

The transposed text is encrypted using the Data Encryption Standard in ECB mode with PKCS7 padding. Each 8-byte block undergoes 16 rounds of permutation and substitution. The final output is hex-encoded for safe storage and transmission. Note: DES is included here for academic demonstration.
